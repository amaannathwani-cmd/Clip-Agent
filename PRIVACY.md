# Privacy Policy

clip-agent is a personal automation tool. It picks Twitch clips, edits them into vertical videos, and uploads them to the owner's own YouTube channel.

## What data it uses

It uses Google OAuth with the YouTube upload scope only, so it can upload videos to the owner's channel. It does not read, collect, store, sell or share any other Google user data. OAuth credentials are kept as encrypted GitHub Actions secrets and are used only to upload videos.

## Who can use it

The app is used only by its owner. No other users sign in to it.

## Contact

For questions, open an issue on this repository.
